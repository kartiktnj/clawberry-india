# Project instructions

## Changelog

Keep `CHANGELOG.md` (project root) up to date, day by day:

- Whenever code changes are made in a session, before wrapping up, add an entry to `CHANGELOG.md` under today's date.
- If a section for today's date (`## YYYY-MM-DD`) already exists (e.g. from an earlier session the same day), append to it instead of creating a duplicate date heading.
- New dates go at the top of the file (newest first).
- Group entries by page/area (e.g. Homepage, About page, Shop & catalogue, Contact), matching the existing format in the file.
- Tag each entry **Added**, **Changed**, or **Fixed**, with one concise sentence explaining what changed and why it matters - written for a human reading the log later, not a raw diff summary.
- Skip changes that were made and then fully reverted within the same session - only log the net, final outcome.
